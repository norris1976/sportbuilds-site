# Alternative hero directions (mockups only, not deployed)

Both use the same self-hosted fonts and the single gold accent as the chosen design (`/`), so they can be compared like for like. They are standalone HTML (open in a browser from this folder) with a rendered PNG each.

- **alt-1-scoreboard** (`alt-1-scoreboard.png`): dark, stadium-scoreboard feel. The headline sits beside a big gold "23:45" result panel in the mono label style; reads as a data publication first.
- **alt-2-cover** (`alt-2-cover.png`): loud gold magazine cover. Oversized condensed headline with an inverted "week." block and a tilted, hard-shadowed card for the latest build; reads as a maker's zine first.

The chosen direction (on the preview) sits between them: paper-and-ink editorial layout, one gold accent, real screenshots of the live tool.
